# บทบาท Infrastructure

**เรียกบทบาทนี้เมื่อผู้ใช้ระบุ** Infrastructure, Infra, Docker หรือ Compose

## หน้าที่และไฟล์ที่ใช้งาน

- ดูแล Compose, พอร์ต ข้อกำหนดสภาพแวดล้อม และวิธีเปิดระบบจากเครื่องอื่น เริ่มที่ [ข้อมูล Infrastructure](infrastructure.md)

## งานรอบนี้

เปิด [PLAN.md](PLAN.md) เพื่อดูงานและผู้รับผิดชอบที่ทีมระบุ เมื่อได้รับเพียงชื่อตำแหน่ง ให้สรุปหน้าที่ตามหมวดที่ระบุและบอกข้อมูลที่ต้องใช้เริ่มรอบนั้น ระบุบริการและสภาพแวดล้อมที่รับงาน พร้อมผลตรวจ config หรือการเริ่มบริการ

## จุดส่งต่องาน

แจ้งฝ่ายที่ใช้บริการเมื่อพอร์ต URL หรือวิธีเปิดเปลี่ยน และแนบวิธีตรวจสถานะ
