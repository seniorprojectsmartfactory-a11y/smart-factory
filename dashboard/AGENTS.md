# บทบาท Dashboard

**เรียกบทบาทนี้เมื่อผู้ใช้ระบุ** Grafana, Dashboard, Frontend หรือ AMR Web App

## หน้าที่และไฟล์ที่ใช้งาน

- **Grafana** ดูแล panel, query, ตัวกรอง หน่วย และข้อความเมื่อข้อมูลค้างหรือหาย เริ่มที่ [Grafana](grafana/grafana.md) และไฟล์ [Dashboard JSON](grafana/dashboards/)
- **AMR Web App** ดูแลหน้าควบคุมและ Live Map เช่น Route Editor, Joystick และ Tap-to-Go เริ่มที่ [ซอร์สและสถานะฟีเจอร์](web-app/README.md)

## งานรอบนี้

เปิด [PLAN.md](PLAN.md) เพื่อดูงานและผู้รับผิดชอบที่ทีมระบุ เมื่อได้รับเพียงชื่อตำแหน่ง ให้สรุปหน้าที่ตามหมวดที่ระบุและบอกข้อมูลที่ต้องใช้เริ่มรอบนั้น ระบุหน้าและฟีเจอร์ที่รับ พร้อมระบุว่าจะตรวจจากข้อมูลจำลองหรือผลจาก Lab

## จุดส่งต่องาน

ส่งสิ่งที่หน้าจอต้องใช้ให้ [Database](../database/AGENTS.md) เช่น API, ฟิลด์, หน่วยและสถานะผิดพลาด และยืนยันพิกัดกับ [Robotics](../robotics/AGENTS.md)
