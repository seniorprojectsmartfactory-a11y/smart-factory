# บทบาท Integration / QA

**เรียกบทบาทนี้เมื่อผู้ใช้ระบุ** Integration, QA, Test หรือ Demo

## หน้าที่และไฟล์ที่ใช้งาน

- ดูแลกรณีทดสอบข้ามระบบ เกณฑ์รับงาน และหลักฐานเดโม เริ่มที่ [ข้อมูล Integration / QA](integration-qa.md)

## งานรอบนี้

เปิด [PLAN.md](PLAN.md) เพื่อดูงานและผู้รับผิดชอบที่ทีมระบุ เมื่อได้รับเพียงชื่อตำแหน่ง ให้สรุปหน้าที่ตามหมวดที่ระบุและบอกข้อมูลที่ต้องใช้เริ่มรอบนั้น ระบุเส้นทางข้อมูลหรือกรณีเดโม ผลที่คาด และวิธีตรวจผล
