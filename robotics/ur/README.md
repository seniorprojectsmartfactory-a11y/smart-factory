# UR

งานแขน UR มีสองส่วนที่เกี่ยวข้องกับทีมอื่น

- **ลำดับรับและส่งตะกร้า** ใช้ [เว็บ Floor 9 3D](../floor9-3d.md) สำหรับดูตำแหน่งแขน จุดจอด และจังหวะส่งต่อ ผลทดสอบกับแขนและมือจับจริงให้ลงใน [แผน Robotics](../PLAN.md)
- **สถานะผ่านเครือข่าย Lab** ตาม handoff วันที่ 19 พ.ย. 2026 ให้เริ่มยืนยันการอ่านสถานะ UR หนึ่งตัวผ่าน LAN แล้วตรวจ Wi-Fi และการกลับมาอ่านข้อมูลหลังขาดการเชื่อมต่อ ยังไม่มีผล Lab ยืนยันในเอกสารนั้น

เมื่ออ่านสถานะได้ ให้ส่ง robot ID, เวลารับข้อมูล, robot mode, program state และ safety state ที่อ่านได้จริงให้ [Database](../../database/database.md) กับ [Dashboard](../../dashboard/dashboard.md) เพื่อแสดงสถานะสดและข้อมูลค้าง
