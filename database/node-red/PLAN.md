# แผนงาน Automation · Node-RED

## เป้าหมายรอบนี้

Flow หรือ API ไหนต้องปรับก่อน และจะจำลอง payload สำหรับทดสอบอย่างไร

## รายการงาน

| งาน | ผู้ทำ | สถานะ | ลิงก์ไฟล์งาน | ผลที่ใช้ตรวจรับ |
|---|---|---|---|---|
| กล้องตรวจ QC ที่สถานี A | Woray | มีแผนทดสอบ | [Handoff สถานี A](../../docs/roles/amr-kitting-station-a-handoff.md) | ผล Set A/B และกรณีของขาด ผิดชนิด หรือกล้องอ่านไม่ได้ |

## จุดส่งต่อและผลทดสอบ

ตกลงสัญญาณขาเข้ากับ IIoT และข้อมูลขาออกกับ Database และ Grafana

เพิ่มลิงก์ข้อสรุปหรือหลักฐานเมื่อมีผลทดสอบ
