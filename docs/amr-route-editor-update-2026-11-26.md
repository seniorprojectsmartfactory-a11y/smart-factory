# อัปเดต AMR Route Editor · 26 พฤศจิกายน 2569

## สิ่งที่พัฒนา

| ส่วน | การเปลี่ยนแปลง |
| --- | --- |
| หน้าแผนที่ | เปิดผังชั้น 9 แบบเต็มชั้นและแสดง AMR จำลองทั้ง 3 คัน กลิ้งลูกกลิ้งบนผังเพื่อซูม เลือก AMR หรือเริ่มจำลองได้โดยคงมุมมองเดิม |
| AMR | เลือก AMR และ Mission แยกกันเพื่อทดลองวิ่ง รถจำลองเดินทางจากจุดเริ่มที่บันทึกไว้ใน Mission |
| คลัง Mission | วาดหรือปรับเส้นตรงและเส้นโค้งบนผัง ทดลองเส้นทางก่อนบันทึก บันทึกทับ สร้าง Mission ใหม่ หรือลบและคืน Mission ที่เพิ่งลบ |
| System Flow | เพิ่ม เอาออก และจัดลำดับขั้น แต่ละขั้นเลือก Mission จากคลังกลางและระบุ AMR ที่ทำงาน เปิดเงื่อนไขเพื่อกำหนดขั้นที่ต้องรอได้ |
| การจำลอง | มี Flow ตัวอย่างแบบวิ่งต่อกันและแบบที่ขั้นหลังเริ่มพร้อมกันเมื่อขั้นแรกเสร็จ รถคันเดียวจะรับงานทีละขั้น |
| ข้อมูลที่บันทึก | คลัง Mission และ System Flow เก็บในเบราว์เซอร์เดิม เมื่อเปิดข้อมูลรุ่นก่อน ระบบจะนำเส้นทางและการมอบหมายงานเดิมมาใช้ในโครงสร้างใหม่ |

เมื่อมี System Flow ใช้ Mission อยู่ ระบบจะแสดงชื่อ Flow ที่อ้างอิง ให้เปลี่ยน Mission ในขั้นนั้นหรือเอาขั้นออกก่อนลบ การตั้งเงื่อนไขรอกันเป็นวงวนจะถูกปฏิเสธก่อนบันทึก

## ผลตรวจสอบ

- ทดสอบบน Node-RED พอร์ต 1881 ว่ากลิ้งลูกกลิ้งเพื่อซูมได้ และมุมมองผังคงเดิมเมื่อเลือก AMR หรือเริ่มจำลอง
- ทดสอบให้ AMR 3 วิ่งตาม Mission ที่เลือก และทดสอบ Flow ทั้งแบบต่อกันและเริ่มงานพร้อมกัน
- การเคลื่อนที่ในหน้านี้เป็นการจำลองในเบราว์เซอร์บนผังชั้น 9
