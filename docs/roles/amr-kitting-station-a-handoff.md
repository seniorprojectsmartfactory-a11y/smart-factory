# Capstone — Handoff สถานีจัดชุด A และ AMR ขนส่ง

จาก YUI / Woray ถึง AI ใน Lab และทีม Robotics · 23 พฤศจิกายน 2026

**สถานะ** ทีมมีแนวทางสำหรับเดโมรอบแรกแล้ว รอรูป ขนาดอุปกรณ์จริง และการทดสอบใน Lab งานรอบถัดไปคือเลือกระหว่างจัดชุดบนโต๊ะแล้วโหลดทั้งถาด กับจัดชุดลงถาดบนรถโดยตรง

## เดโมหลัก

ใช้ **UR ตั้งโต๊ะประจำ A หนึ่งตัว** และ **AMR ขนส่งที่ไม่มีแขนหนึ่งคัน** ให้ UR จัดชิ้นส่วนตามออเดอร์ในถาดสามช่อง ตรวจด้วยกล้อง และให้รถขนถาดที่ผ่านไปจุดรับปลายทาง เดโมรอบแรกถือว่าจบรอบเมื่อรถจอดถึงจุดรับพร้อมถาด

| ออเดอร์ | S1 | S2 | S3 |
|---|---|---|---|
| Set A | แหวน | บล็อก | แหวน |
| Set B | บล็อก | แหวน | บล็อก |

1. ผู้ใช้กด Set A หรือ Set B บนเว็บ ระบบส่งรหัสออเดอร์พร้อมสูตรให้ UR-A และใช้สูตรเดิมจนจบรอบ
2. UR-A หยิบชิ้นส่วนจากจุดป้อนและจัดลงถาดบนโต๊ะยาวข้างแขน
3. หลัง UR แจ้งว่าจัดเสร็จ กล้องตรวจว่าชนิดและจำนวนตรงตามสูตรของออเดอร์นั้น ถ้าขาดหรือผิดช่อง ให้ค้างถาดที่ A และแสดงผลตรวจบนเว็บ
4. เมื่อ QC ผ่านและรถจอดนิ่งพร้อมรับ ให้ UR-A ยกถาดลงตำแหน่งรับบนพื้นบรรทุก ยืนยันว่าถาดอยู่บนรถและแขนพ้นจุดจอดก่อนปล่อยรถไปจุดรับ
5. บันทึกผลจัดชุด ผล QC ผลยืนยันถาดบนรถ และผลถึงปลายทาง โดยผูกกับออเดอร์เดียวกัน

## ทางเลือกที่จะตัดสินที่ Lab

| แบบ | สิ่งที่ต้องพิสูจน์ | ผลต่อรอบงาน |
|---|---|---|
| **จัดบนโต๊ะแล้วโหลดทั้งถาด** | มือคีบหยิบชิ้นเล็กและจับถาดเต็มได้ จุดวางบนรถอยู่ในท่าที่แขนเข้าถึงได้ และรถกลับมาจอดซ้ำตรงพอสำหรับวางถาด | ทำถาดและตรวจได้ก่อนรถมาถึง |
| **จัดลงถาดบนรถโดยตรง** | รถจอดพร้อมถาดเปล่า UR เข้าถึงครบสามช่อง และกล้องเห็นครบที่จุดจอด | ลดการยกทั้งถาด รถจอดรอระหว่างจัดชุดกับตรวจ |

พื้นที่ด้านหลัง UR เป็นตำแหน่งเสนอสำหรับวัตถุดิบหรือถาดเปล่า ให้ดูท่าเข้าหาของและพื้นที่กวาดของแขนระหว่างจุดป้อน โต๊ะ และรถก่อนยืนยันตำแหน่ง

## งานแรกเมื่อถึง Lab

1. ถ่ายรูปด้านข้างให้เห็นฐาน UR โต๊ะยาว และรถตอนจอดหน้าโต๊ะ ถ่ายมุมสูงให้เห็นทั้งพื้นที่จอดและพื้นที่หลังแขน
2. วัดความสูงผิวโต๊ะและพื้นบรรทุกจากพื้นเดียวกัน วัดระยะในแนวราบจากศูนย์กลางฐาน UR ถึงจุดวางถาดบนรถและจุดป้อนด้านหลัง ระบุรุ่น UR, มือคีบ, รถ และขนาดกับน้ำหนักของถาดเต็ม
3. ให้ผู้ควบคุม Lab ทบทวนตำแหน่งจอด แนวเคลื่อนแขน จุดยืนยันถาดบนรถ และการมองเห็นของกล้องก่อนอนุมัติรอบทดสอบเคลื่อนที่จริง ใช้ข้อมูลจำลองเพื่อทดสอบลำดับสถานะระหว่างรอ
4. เมื่อพร้อม ให้ลอง Set A, Set B และกรณีจงใจขาด S3 ตรวจว่าเมื่อ QC ค้าง รถยังไม่เริ่มภารกิจ และเมื่อ QC ผ่าน รถจอดถึงจุดรับพร้อมถาด เก็บผลแยกว่ามาจากซิมหรือ Lab จริง

**สิ่งที่ให้ AI ใน Lab ส่งกลับ** รูปพร้อมระยะ ผลตรวจมือคีบ จุดจอดและกล้อง แบบที่เสนอให้ใช้พร้อมเหตุผล และเงื่อนไขที่ยังต้องตรวจเพิ่ม ระบุผลที่ทำซ้ำได้และอาการเมื่อทดสอบไม่ผ่าน

## บทบาทของ AMR ติด UR

เป็นเดโมต่อยอดสำหรับปลายทางที่ไม่มีแขนประจำ ใช้สถานี A เดิมให้ UR-A โหลดถาดขึ้น AMR ติด UR แล้วให้แขนบนรถยกถาดลงโต๊ะปลายทางหลังรถจอด แนวทางนี้เพิ่มความสามารถส่งของถึงโต๊ะปลายทางโดยใช้รถหนึ่งคันต่อรอบ
