# Dashboard / Grafana และ Live Map

**ผู้รับผิดชอบ** ____________________  
**ผู้สำรอง** ____________________

ดูแลการแสดงผลเซนเซอร์ สถานะอุปกรณ์ และตำแหน่ง AMR ให้ผู้ใช้แยกข้อมูลล่าสุด ข้อมูลค้าง และข้อมูลจำลองได้

งานรับช่วงหน้าจอ AMR และสถานะฟีเจอร์ 1–6 อยู่ใน [AMR Handoff](amr-handoff.md)

## งานหลัก

- ดูแล Grafana ที่ [localhost:3000](http://localhost:3000) โดยตรวจ datasource, query, หน่วย, เวลาล่าสุด และช่วง refresh ของแผงที่แก้
- ดูแล [หน้า Live Map ใน Node-RED](http://localhost:1881/smart-factory/live-map) และประสาน Automation เมื่อแก้ flow ที่สร้างหน้าเว็บหรือส่งข้อมูลสถานะ
- รับ map ID, รุ่น และกรอบพิกัดจาก Robotics แสดงตำแหน่งหุ่นยนต์เมื่อข้อมูลตรงกับแผนที่ที่ตรวจแล้ว และติดป้ายเมื่อค่าค้างหรือรอเทียบพิกัด
- ในงานต่อยอด แสดงเส้นทางที่วางไว้และรอยวิ่งจริงให้แยกกันชัดเจน ใช้ ID ของรอบภารกิจที่ตกลงกับ Database และระบุฟีเจอร์ที่ยังเป็นต้นแบบ

## ไฟล์ที่ใช้

- ตัวอย่างไฟล์แดชบอร์ด (`grafana/dashboards/`) และ บันทึกการทำ Live Map เดิม (`Progress-2026-11-14.md`)
- สำเนาของ dashboard ที่ใช้งานบน Grafana 13.2.3 อยู่ในฐาน Grafana ของ Docker ให้ export JSON ของ dashboard ที่แก้เพื่อส่งรีวิว

## ส่งมอบเมื่อ

- ส่ง JSON และภาพก่อน–หลัง พร้อมชื่อ dashboard หรือ UID และรายการ panel ที่แก้
- ทดสอบทั้งกรณีมีข้อมูลใหม่, ไม่มีข้อมูลในช่วงเวลา และอุปกรณ์ offline
- สำหรับ Live Map บันทึก map ID ที่ใช้และยืนยันกับ Robotics ว่าการวาง marker ตรงกับจุดอ้างอิง หากเป็นการเทียบโดยประมาณให้ระบุไว้บนหน้าแสดงผล
