# Integration / QA และ Demo

**ผู้รับผิดชอบ** ____________________  
**ผู้สำรอง** ____________________

ดูแลการตรวจรับข้ามตำแหน่งและเตรียมหลักฐานเดโม เพื่อให้ทีมรู้ว่าผ่านตั้งแต่อุปกรณ์จนถึงแผงแสดงผลส่วนไหนแล้ว

## งานหลัก

- ตกลงสถานการณ์ทดสอบกับเจ้าของงานแต่ละตำแหน่ง ระบุเครื่องที่ใช้ รุ่นซอร์ส ชุดข้อมูล เวลาทดสอบ ผลที่คาด และผู้รับช่วงหากพบปัญหา
- ตรวจเส้นทาง WISE → Node-RED → InfluxDB → Grafana ด้วยสัญญาณทดสอบหนึ่งชุด เทียบเวลาข้อมูลและค่าที่แต่ละระบบ พร้อมทดสอบกรณีอุปกรณ์หยุดส่ง
- ตรวจ Live Map ร่วมกับ Robotics และ Dashboard โดยจับคู่ robot ID, map ID และช่วงเวลา แล้วเทียบตำแหน่งกับจุดอ้างอิงที่ Lab ยืนยัน
- ดูแลลำดับเดโมและการส่งมอบหลักฐาน ประสานผู้ควบคุม Lab เมื่อมีการทดสอบหุ่นจริง สรุปแยกผลจากข้อมูลจำลองกับผลจากอุปกรณ์จริง

## หลักฐานที่ส่งมอบ

| รายการ | ข้อมูลที่ต้องบันทึก |
|---|---|
| การทดสอบ | วันที่, commit หรือเวอร์ชัน, สภาพแวดล้อม, กรณีทดสอบ |
| ผล | ค่าที่คาด, ค่าที่พบ, สถานะผ่าน / ไม่ผ่าน / ยังไม่ทดสอบ |
| ข้อผิดพลาด | วิธีทำซ้ำ, หลักฐาน, ผู้รับช่วง |
| เดโม | ขั้นที่แสดงได้, ขั้นที่ยังใช้ข้อมูลจำลอง, เงื่อนไขหน้างาน |
