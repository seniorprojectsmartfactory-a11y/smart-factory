# Robotics / AMR Route Lab และ UR

**ผู้รับผิดชอบ** ____________________  
**ผู้สำรอง** ____________________

ดูแลข้อมูลอ้างอิงหุ่นยนต์ ความพร้อมของแผนที่ และการตรวจรับ AMR Route Lab กับ UR ร่วมกับผู้ควบคุม Lab

## งานหลัก

- ตรวจรุ่นและเวอร์ชันหุ่นยนต์ robot ID, map ID, กรอบพิกัด และสถานะที่ระบบอ่านได้จากเครื่อง Lab ส่งข้อมูลอ้างอิงแก่ Automation, Database และ Dashboard
- ดูแลหน้า AMR Route Lab กับการแสดงจุดเริ่ม จุดหมาย และผลภารกิจ ทบทวนข้อมูลเส้นทางกับผู้ควบคุม Lab ก่อนทดสอบกับหุ่นจริง
- ดูแลส่วนเชื่อม UR และ Robotiq ในขอบเขตของโปรเจกต์ บันทึกเงื่อนไขที่เครื่องพร้อมทดสอบและข้อจำกัดของการทดสอบรอบนั้น
- ประสาน Infrastructure เรื่องเครือข่าย Lab และพอร์ตทดสอบ เพราะ AMR Route Lab และ Node-RED ในชุด Docker ใช้พอร์ตโฮสต์ `1881` ร่วมกันในค่าปัจจุบัน

## ไฟล์ที่ใช้

- หน้าเว็บ AMR Route Lab (`amr-route-lab/index.html`), เซิร์ฟเวอร์ Route Lab (`amr-route-lab/server.cjs`) และ ภาพแผนที่ Route Lab (`amr-route-lab/floor9.png`)
- โค้ด UR และ Robotiq (`ur-gripper/`) และ เอกสารส่งต่อ Lab (`2026-11-16_amr-dashboard-lab-handoff woray.md`)

## ส่งมอบเมื่อ

- ส่งรายการอุปกรณ์และแผนที่ที่ตรวจแล้ว พร้อมวันที่และแหล่งที่มาของข้อมูล
- ส่งหลักฐานการทดสอบหน้า Route Lab และสถานะอุปกรณ์ โดยระบุให้ชัดว่าส่วนใดจำลองและส่วนใดตรวจที่ Lab จริง
- แจ้ง Dashboard กับ Database เมื่อเปลี่ยนกรอบพิกัด รุ่นแผนที่ หรือรูปแบบผลภารกิจ
