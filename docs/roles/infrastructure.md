ดูแลให้สมาชิกเปิดสภาพแวดล้อมและส่งงานจากเครื่องอื่นได้ และให้บริการ Lab กลับมาทำงานหลัง Docker เริ่มใหม่

## งานหลัก

- ดูแล Compose กลุ่ม `smart-factory` และพอร์ตโฮสต์ Grafana `3000`, InfluxDB หลัก `8086`, InfluxDB รุ่นก่อน `8087` และ Node-RED `1881`
- ตรวจ health endpoint, restart policy และการเก็บข้อมูลบนดิสก์หลังเปลี่ยน Compose ประสาน Database ก่อนย้ายหรือกู้คืน volume
- จัดทำขั้นตอนสำหรับเครื่องใหม่ โดยระบุเวอร์ชันบริการ ค่า environment ตัวอย่าง พอร์ตที่ใช้ และสิ่งที่ต้องเข้าถึงเครือข่าย Lab สำหรับทดสอบจริง
- ดูแล repository `seniorprojectsmartfactory-a11y/smart-factory` และการส่งงานแบบ branch กับ pull request ตรวจไฟล์ก่อนเผยแพร่ให้เหลือเฉพาะซอร์ส ตัวอย่างการตั้งค่า และเอกสารที่เปิดเผยได้

## ไฟล์ที่ใช้

- Compose ชุดที่ใช้งาน (`infra/docker-migration/compose.yaml`) และ กฎ Git ignore (`.gitignore`)
- Compose ชุดทดลอง (`notebook/project-dashboard/compose.yaml`) ใช้ประกอบการทดสอบข้อมูลจำลอง โดยตรวจพอร์ตที่ชนกับชุด Lab ก่อนเปิด

## ส่งมอบเมื่อ

- มีคำสั่งเปิดและตรวจสถานะที่สมาชิกอีกคนทำตามได้ พร้อมผลตรวจว่า Grafana และ InfluxDB ตอบที่พอร์ตที่กำหนด
- pull request ระบุวิธีทดสอบ ผลกระทบต่อพอร์ตหรือข้อมูล และวิธีย้อนกลับเมื่อจำเป็น
- รหัสผ่าน โทเคน ไฟล์ credentials ฐานข้อมูลจริง และข้อมูลเครือข่าย Lab อยู่ในพื้นที่ที่ทีมจำกัดสิทธิ์เข้าถึง
