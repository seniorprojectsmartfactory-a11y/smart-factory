# IIoT / อุปกรณ์และเครือข่าย

**ผู้รับผิดชอบ** ____________________  
**ผู้สำรอง** ____________________

ดูแลการเชื่อมต่อจากเซนเซอร์จริงผ่าน WISE-4012 และ WISE-4250 จนอ่านสัญญาณได้จากเครื่อง Lab

## งานหลัก

- จัดทำรายการอุปกรณ์ จุดต่อสาย ช่อง DI/DO/AI และค่าเครือข่ายที่ตรวจแล้ว โดยเก็บค่าเฉพาะหน้างานในพื้นที่ของทีม
- ตรวจ Modbus TCP จากเครื่อง Lab และยืนยัน address, ชนิดข้อมูล, หน่วย และความหมายของค่าด้วยสัญญาณจากอุปกรณ์จริง
- ตรวจปัญหาตามลำดับจากเซนเซอร์ ช่อง I/O และเครือข่ายไปถึงค่าที่ Automation อ่านได้ ประสาน Infrastructure เมื่อ Windows อ่านได้แต่ Docker อ่านไม่ได้
- ส่งตาราง mapping กับตัวอย่างค่าที่ตรวจแล้วให้ Automation และแจ้งทีมเมื่อย้ายช่อง เปลี่ยนเซนเซอร์ หรือแก้สเกลสัญญาณ

## ไฟล์ที่ใช้

- รายงาน Modbus WISE-4012 (`WISE-4012_Node-RED_Modbus_Report_2026-09-16.md`)
- รายงานระบบตรวจจับวัตถุ (`Object-Detection-Implementation-Report-2026-09-17.md`) และ ผลทดสอบ EZ-18M / DI1 (`EZ-18M-Integration-Report-2026-09-22.md`)

## ส่งมอบเมื่อ

- มีตารางอุปกรณ์ ช่อง I/O และ Modbus mapping ที่ระบุวันที่ทดสอบ พร้อมตัวอย่างค่าดิบและหน่วยที่ยืนยันแล้ว
- Automation อ่านค่าได้และตรวจพบการเปลี่ยนสถานะตามสัญญาณจริงอย่างน้อยหนึ่งกรณี ระบุช่องที่ยังไม่ได้ยืนยันไว้ในตาราง
