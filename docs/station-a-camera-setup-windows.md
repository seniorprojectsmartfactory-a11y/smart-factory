# สถานี A · ตั้งกล้อง RealSense และรัน QC บน Windows

**เป้าหมาย** ให้กล้องมองลงไปในกล่องบน AMR ตรวจบล็อกกับแหวนหลัง UR จัดของเสร็จและก่อนปิดฝา **Woray ฝั่ง Automation** ดูแลการตั้งกล้องและ Vision QC ส่วน **Robotics** ทดสอบการเชื่อมต่อและภาพสด และช่วยยืนยันตำแหน่งรถจอดกับจังหวะที่แขนพ้นภาพ

## 1. เปิดภาพสีบน Windows

ต่อ RealSense D435i ผ่าน USB เปิด RealSense Viewer แล้วเลือกสตรีม **Color** ใช้ `640 × 480` เพื่อทดสอบให้ตรงกับสคริปต์ QC ปัจจุบัน ตรวจว่าสีบล็อกและแหวนแยกกันได้ บันทึกรุ่นกล้องและความละเอียดที่ใช้ ผล Lab วันที่ 26 พฤศจิกายนยืนยันแล้วว่ากล้องสองตัวเปิดภาพ RGB `1280 × 720` ที่สตรีมรายงาน `30 fps` ผ่านหน้าทดสอบ Node-RED ให้ตรวจโปรไฟล์ `640 × 480` เพิ่มตอนลองสคริปต์ [บันทึกทดสอบ RGB และ Node-RED Flow](../robotics/station-a-realsense-rgb.md) · [RealSense SDK และ Viewer](https://github.com/realsenseai/librealsense/releases)

## 2. ตั้งกล้องชั่วคราวแล้วเลือกความสูงจากภาพจริง

1. ให้ AMR จอดพร้อมกล่องจริงที่จุดตรวจ ยึดกล้องชั่วคราวให้มองตรงลงกลางกล่องเพื่อปรับระดับได้ โดยให้ผู้ควบคุม Lab ตรวจตำแหน่งขาตั้งกับแนวเคลื่อนแขนก่อนลองขยับอุปกรณ์
2. ใช้ตลับเมตรวัดจากหน้ากล้องถึง **พื้นด้านในกล่อง** ลอง 2–3 ระดับ เช่น `40`, `50`, `60 ซม.` เป็นระยะเริ่มทดลอง ปรับช่วงตามขนาดกล่องและข้อจำกัดขาตั้ง
3. ถ่ายแต่ละระดับโดยย้ายแหวนและบล็อกจากกลางกล่องไปใกล้มุม เลือกระดับที่ยังเห็นพื้นกล่องครบ เห็นรูแหวนและขอบบล็อก และมีพื้นที่เผื่อรถจอดคลาด

## 3. เช็กความคม ล็อกมุม และลองจอดซ้ำ

วางตารางหมากรุกแบนบนพื้นกล่องที่ความสูงที่เลือก ใช้เส้นตารางดูความคมตรงกลางภาพและใกล้มุม จากนั้นถ่ายชิ้นงานจริงซ้ำ เปิดไฟที่ตั้งใจใช้ประจำสถานีและเช็กเงาขอบกล่อง ลองให้ AMR กลับมาจอดใหม่แล้วดูว่าพื้นกล่องยังอยู่ในกรอบตรวจครบ จึงล็อกขาตั้งและบันทึกความสูง มุม ความละเอียด และตำแหน่งจอด

ถ้าภายหลังต้องแก้ภาพบิดหรือวัดตำแหน่งจริงจากพิกเซล ให้ทำ camera calibration ด้วยตารางที่รู้ขนาดช่องและภาพหลายมุม ขั้นตรวจชนิดและจำนวนด้วย ROI ใช้ภาพจากมุมคงที่ได้ [OpenCV — Camera Calibration](https://docs.opencv.org/4.13.0/dc/d43/tutorial_camera_calibration_square_chess.html)

## 4. รันโค้ดกับภาพนิ่งก่อน

ใช้โฟลเดอร์ต้นแบบ **`Capstone/vision/packing-qc/` ใน workspace ForAI** ซึ่งมี `packing_qc.py`, `inspection.json` และ `requirements.txt` โค้ดอยู่ใน workspace นอก repo Smart Factory ให้เปิด PowerShell ในโฟลเดอร์ต้นแบบบนเครื่อง Windows ที่ใช้ทดสอบ

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe .\packing_qc.py --camera --capture-only .\sample-b.png
.\.venv\Scripts\python.exe .\packing_qc.py --image .\sample-b.png --recipe B --roi 100 60 440 360 --output .\qc-b.png
```

ปิดโปรแกรมดูภาพถ้ามันจับกล้องอยู่ก่อนรันสคริปต์ ค่า `100 60 440 360` เป็นตัวอย่าง `X Y W H` ให้วัดจากภาพสีจริง โดย `X Y` คือมุมซ้ายบนของกรอบ และ `W H` คือขนาดกรอบเป็นพิกเซล ตั้งกรอบให้ครอบพื้นกล่องโดยเหลือขอบเผื่อชิ้นงาน ปรับ `hsv_min`, `hsv_max` และ `area_px` ใน `inspection.json` จากภาพชุดแรก แล้วใช้ภาพอีกชุดตรวจซ้ำ

| กรณี | สิ่งที่ต้องเห็นจากผล QC |
|---|---|
| Set A บล็อก 3 ชิ้น และ Set B บล็อก 2 ชิ้น + แหวน 1 ชิ้น | `PASS` ตรงออเดอร์ |
| กล่องเปล่า ของขาด ของเกิน หรือใส่บล็อก 3 ชิ้นใน Set B | กล่องผิดต้องไม่หลุดเป็น `PASS` |
| ชิ้นงานติดขอบ แตะกัน หรือซ้อนกัน | ถ้าจำแนกไม่ได้ให้แก้แนววางหรือกรอบตรวจแล้วลองซ้ำ ชิ้นที่บังมิดยังตรวจด้วยภาพเดียวไม่ได้ |

## 5. รันจากกล้องจริงก่อนปิดฝา

ใช้สูตรและ ROI ที่ยืนยันจากภาพนิ่งแล้ว เริ่มจับภาพเมื่อรถจอดนิ่งและ UR ถอนพ้นภาพ

```powershell
.\.venv\Scripts\python.exe .\packing_qc.py --camera --recipe B --roi 100 60 440 360 --output .\qc-live.png
```

ลองกล่องถูกและกล่องผิดหลายรอบโดยให้รถกลับมาจอดใหม่ บันทึกผล JSON และภาพตีกรอบ ฝั่ง Automation ใช้ `PASS` สำหรับไปขั้นปิดฝาหลังทดสอบกับ Lab แล้ว ส่วน `FAIL`, `HOLD` และ `ERROR` ให้ค้างกล่องเปิดไว้ ต้นแบบปัจจุบันส่งผลตรวจอย่างเดียว การต่อเงื่อนไขปิดฝาและปล่อยรถเป็นงาน Integration ตาม [Handoff สถานี A](roles/amr-kitting-station-a-handoff.md)

## 6. ตัดสินใจเรื่อง train หลังรู้ข้อผิดพลาดจริง

ใช้ OpenCV ต่อถ้าแยกชนิดและนับได้ตรงทั้งออเดอร์ถูกและผิด ถ้าคุมแสงและจุดวางแล้วแต่สีหรือรูปทรงยังสับสน ให้เก็บภาพจากกล้องมุมจริง ตีป้าย `block` / `ring` รายชิ้น และแยกภาพทดสอบออกจากชุดฝึก ใช้กรณีทดสอบเดิมเทียบว่าโมเดลลดกล่องผิดที่หลุดเป็นผ่านได้หรือไม่

**ผลที่ต้องเก็บกลับจาก Lab** ความสูงกล้องที่เลือกและรูปขาตั้ง ภาพดิบกับภาพตีกรอบของ A/B และกล่องผิด ค่า ROI ผลจอดซ้ำ และข้อผิดพลาดที่ยังเจอ
